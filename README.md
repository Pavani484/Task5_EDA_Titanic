# Titanic Exploratory Data Analysis

## Objective
Perform Exploratory Data Analysis (EDA) on Titanic Dataset.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data Inspection
- Missing Value Analysis
- Histograms
- Boxplots
- Scatterplots
- Correlation Heatmap
- Pairplot

## Key Findings
- Females survived more than males.
- First-class passengers had better survival rates.
- Most passengers were between 20 and 40 years old.
- Fare contains outliers.
